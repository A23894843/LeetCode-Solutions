A structured collection of **LeetCode problem solutions implemented in C++**, created to build strong Data Structures & Algorithms (DSA) fundamentals through consistent problem solving.

The repository contains individual problem folders with the corresponding **C++ solution** and a **problem-specific README**, making each solution easy to study, review, and revisit.

## 🎯 Purpose

This repository is part of my ongoing DSA practice and is focused on:

* Improving problem-solving and logical thinking
* Understanding common DSA patterns and techniques
* Writing clean and efficient C++ solutions
* Studying time and space complexity
* Preparing for coding interviews and competitive programming
* Tracking progress while solving problems of increasing difficulty

## 🚀 How to Use

Clone the repository:

```bash
git clone https://github.com/A23894843/LeetCode-Solutions.git
cd LeetCode-Solutions
```

Open any problem directory:

```bash
cd 1-two-sum
```

Review the problem explanation and implementation.

For files that support standalone compilation:

```bash
g++ -std=c++17 two-sum.cpp -o solution
./solution
```

Some solutions use LeetCode's expected:

```cpp
class Solution
```

format and are therefore intended to be submitted directly through the LeetCode editor rather than compiled as standalone programs.

## 🔍 Problem-Solving Workflow

My general approach to each problem is:

1. Understand the problem and constraints.
2. Identify the underlying DSA pattern.
3. Develop a straightforward solution first.
4. Analyze time and space complexity.
5. Look for a better or more scalable approach.
6. Implement the solution cleanly in C++.
7. Document the reasoning for future revision.
